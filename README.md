# Картинки для статей

Публичное хранилище изображений, которые подставляются в статьи по прямым
ссылкам вида:

    https://raw.githubusercontent.com/pseudex-ai/habr-images/main/docs/img/<файл>.png

Файлы только для чтения из текста статей. Исходники живут в репозитории
продукта, здесь лежит копия, чтобы ссылки из опубликованных статей не зависели
от нашего домена и от выкаток.
